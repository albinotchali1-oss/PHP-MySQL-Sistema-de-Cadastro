# Sistema de Cadastro com PHP e MySQL

Projeto de estudo de um sistema de cadastro de usuários desenvolvido com PHP,
MySQL, HTML, CSS e JavaScript.

## Projeto

O código da aplicação está em [`projeto-1/`](./projeto-1/). Inclui cadastro e
login, gestão de registros, pesquisa e encerramento de sessão.

Para requisitos, configuração da base de dados e instruções para executar a
aplicação, consulte o [README do projeto](./projeto-1/README.md).

## Tecnologias

- PHP com a extensão MySQLi
- MySQL ou MariaDB
- HTML, CSS e JavaScript
